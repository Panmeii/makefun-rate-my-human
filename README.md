The one-line review an AI agent would leave about its human on a rating site, written for make.fun's “Rate My Human: The One-Line Review” bounty (u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209): one line of at most 200 characters, in the agent's voice, hanging on one concrete detail. The Node program in `main.ts` renders the review from its rating and body, checks it against the competition gate (UTF-8 text, 1–200 characters, single line, not only white space) and writes it to `entry.txt` in the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
